优先修复 · 01 / 02

确认页：标题被遮挡，标识被截断。

01 步骤切换要留下明确的阅读起点。从手机编辑页底部进入确认页后，标题位于屏幕 y≈31–75px，被高 120px 的吸顶页头完全遮住。建议在步骤切换时，让标题落在页头下方，并保留标题焦点。

02 核对时显示完整 BAP ID。当前确认卡将 BAP ID 单行省略，复制按钮仍在。建议允许标识换行，复制按钮保持独立，便于直接核对。完整标识要求引用核心认知第 6.3 节。

复现步骤与完成标准
  1. 中文浅色，390×844。连接模拟钱包并创建身份，进入“我的身份”。
  2. 打开“编辑资料”，修改简介，滚动至页底，点击“预览确认”。
  3. 确认页标题虽获得焦点，但 y≈31–75px，处于吸顶页头 0–120px 内。编辑页底部截图。

完成标准：进入确认页时，步骤和标题可见；BAP ID 完整可读、可复制；页面无横向溢出。

视觉打磨 · 03

手机表单：让输入更早出现。

390×844 的创建页中，名称输入框从约 y=636px 开始。步骤、标题、说明、身份信息和头像消耗了大部分首屏。建议压缩标题区与身份摘要的纵向间距，缩小头像组占高，保留字段之间的呼吸感。BAP ID 继续可见。

查看原图 · 390×844

完成标准：在这组屏宽下，名称和类型更早进入首屏，说明仍清楚。不要为了缩短页面压小触控目标。

视觉与交互 · 04 / 05

身份卡：轻一点，也更容易操作。

04 调整卡片的纵向比例。短简介场景下，卡片底部仍有较大留白；390×844 首屏内看不到卡外复制入口。建议收紧短内容卡片的高度和上下间距，让复制入口更接近卡片。前后两面仍需完整容纳内容。

05 给翻面一个看得见的入口。卡片有 3D 外观，但首屏缺少明确的翻面提示。建议在卡边加入轻量的“翻面”操作，保留拖动；按键和触屏用户都能发现背面。“查看链上记录”折叠入口继续保留。

完成标准：默认短资料下卡片和复制入口能一起被发现；首次访问即可找到翻面操作；长资料与背面内容不溢出。本轮未重新验证真实手指拖动。

视觉打磨 · 06

身份页：以人物与标识组织信息。

“变化之中，自有坐标。”的字号和空间占比高于身份内容；右侧只有一句简介，却占据整列，“已发布”状态落在较远的底部。建议缩短任务页标题区，将名称、BAP ID 和发布状态组成清晰的信息组；简介紧随其后。短资料下减少空列，长资料再自然展开。

保留优势

品牌气质已经成立。

首页的七线穹顶、地平线与单一蓝色主按钮，形成了克制的视觉秩序。建议保留首页的表达空间；业务操作页使用更紧凑的层次。身份页的 BAP ID 和复制操作，也应继续作为核心内容。
