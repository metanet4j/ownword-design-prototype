# 页面说明与编号样式审查

本轮按用户五条批注检查同类呈现问题，修正已完成，等待视觉复核。领域模型、签名授权、确认数与关联规则保持原有语义。

## 修正范围

| 类型 | 当前呈现 | 覆盖位置 |
| --- | --- | --- |
| 重复小标题 | 删除重复的预览确认、模块标牌，保留有实际含义的状态和字段标签 | Artifact 工作台、创建、确认、选择、转移、查找；身份确认及内容入口、确认页 |
| 常驻解释段落 | 关联历史、签名原理、确认与地址规则改为帮助入口；支持悬浮、聚焦、点击及 Escape | 创建、关联、转移、移除、资产选择、操作结果与授权弹窗 |
| 编号排版 | 使用无衬线纯数字，省略展示前缀 #；长数字保持完整，复制原值 | 共用编号组件及使用它的列表、身份摘要、详情、确认、选择和查找 |
| 实现与模拟说明 | 集中到页脚入口打开的演示面板；产品状态不重复附加模拟、样例字样 | Artifact、内容发布、阅读、Proof 与共用签名展示 |
| 确认信息过密 | 关联等操作取消默认内容占位，Inscription ID 和 Current Outpoint 放入交易详情 | 关联、转移、移除确认；创建确认仍保留所选内容来源 |

关联确认仍显示新资产、操作 BAP ID 和被替换的数字 ID；转移保留接收地址及控制权变化，移除保留数字 ID 不再指向身份的结果。没有把关键决定藏进帮助。上传图片预览沿用原组件。
