# 模块结构与身份页审查

本轮针对用户三条批注，调整模块入口、身份页信息层级与中性视觉，并检查受影响导航。实现与本轮验证完成，等待用户视觉复核。

## 结构依据与落点

模块职责以[核心认知第 5.1 节](../../../../../../system-design/spec/核心认知.md)为准；页面结构和扩展方式以[版本设计第 4.1、4.2 节](../../../../../../system-design/spec/prd/v0.3.0/设计文档v0.3.0-20260918-215142.md)为准。本报告只记录此次审查结果。

| 用户反馈 | 已落实的结果 |
| --- | --- |
| 身份页堆叠多个模块 | 资料和身份标识集中成组；移除内容推广入口与大型 Artifact 管理区。Artifact、内容各用自己的工作区，全局导航切换。 |
| 数字 ID 大块留白、操作重复 | 编号、稳定状态与单一详情入口紧凑排列。未关联提供设置入口，关联异常提供检查入口，不展示失效编号。 |
| “菜单”缺少含义 | 触发器显示当前模块与 S2 向下箭头；下拉分为业务模块与辅助操作，不再推挤正文。 |
| 蓝色描边粗重 | 当前卡片、选项、头像边框及内容标记使用中性色；保留清楚的状态文字和高对比键盘焦点。 |
| 同类标签不明确 | “公开身份”操作改为“查看公开身份”；设置入口明确为“外观与语言”，连接操作明确为“断开钱包”；草稿行的“更多”改为“管理草稿”。 |
| 后续模块如何扩展 | 既有平行模块结构已落实为各自的工作区；扩展方式写入版本设计，不在本版显示未实现入口。 |

使用现有 S2 bundle 的 Button、StatusLight、Card/CardView、字段与弹窗；字体、颜色、间距、圆角引用 S2 token，箭头直接引用 S2 SVG。没有新增组件依赖或改写设计系统副本。

## 本轮发现的交互问题

编辑身份名称后，通过旧导航切到“我的内容”会直接离开，绕过未保存提示。现在身份资料进入内容与 Artifact 均先检查修改状态：“继续编辑”保留原输入，“放弃修改”后才切换目标模块。新增 `check-workspace-navigation.ps1` 固化该回归，并兼容现有 Artifact 审查脚本的新导航入口。

## 验证结果

- 320×568、575×792、1440×1000 代表视口；中文深色与英文浅色。检查身份页、模块下拉、Artifact 与内容首页截图。
- 下拉支持方向键、Tab 顺序、Escape 回焦与外部点击；320px 页面和下拉无横向溢出。
- 身份资料与 Artifact 创建草稿在跨模块切换时正确拦截；取消后输入保留，放弃后进入目标模块。脚本结果见 [regression-check.txt](regression-check.txt)。
- 无资产时设置入口进入 Artifact 工作区，仍可切换内容；当前关联失效时不输出当前数字编号。
- 身份桌面与手机无障碍扫描各 37 项通过、0 违规、0 待确认；下拉内部扫描 10 项通过、0 违规、0 待确认。展开下拉时的整页扫描有 1 项对比度待确认，原因是下拉覆盖了后方按钮；关闭下拉后的身份页及下拉内部均已单独扫描。
- 浏览器运行时错误为 0；日志中仅有既有 Babel 浏览器编译提示及开发信息。
- 最终启动检查通过：身份 92 个断言、内容模型、Artifact 10 组模型、JSX、S2 token 与 harness。登记 14 项任务、33 条 BDD；本轮没有重跑全部浏览器 BDD。

全部钱包与交易继续使用模拟数据。未验证真实钱包、生产 API 或真机 Safari。用户标记截图里的蓝色外框属于浏览器批注，不是产品边框。
