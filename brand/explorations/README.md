# 品牌方向探索 · 2026-09-06

用户要求先看跳出现有框架的方案，再选择。三个概念均为待审阅提案，未应用到现有原型。

- A「自印」：身份归属。开口方印与独立的点，强调用户拥有自己的位置。建议优先考虑，身份含义最贴近产品中心。
- B「言印」：话语署名。错落引号与削切尾部，强调表达的分量；更容易联想到出版和写作。
- C「续章」：记录延续。错位笔画与连续脊线，强调表达的积累；小尺寸较抽象。

设计依据：[核心认知](../../../../_task/system-design/spec/核心认知.md) 第 1 节 Identity、Words、Proof 与用户本次讨论；以上为视觉解释，不新增业务定义。审阅页：[三种品牌方向](../../brand-explorations.html)。
